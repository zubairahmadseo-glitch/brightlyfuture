STEP 2 (Gutenberg): make a pattern once
1. Open any post, add a Group block.
2. Inside it add two Paragraph blocks:
   - first: Quick Answer
   - second: your answer text
3. Select the Group block > right sidebar > Advanced > Additional CSS class(es): bf-qa
4. Select the Group > three dots > Create pattern > name "Quick Answer" > Synced: OFF > Create.

EVERY NEW POST
Type /Quick Answer > insert the pattern > click the second paragraph and type the new answer. No code.

ELEMENTOR INSTEAD
Add a Text Editor widget > write "Quick Answer" on line 1 and the answer as a new paragraph >
Advanced tab > CSS Classes: bf-qa > right-click the widget > Save as Global? NO: use "Save as Template"
and insert that template in each post, then edit the text.
