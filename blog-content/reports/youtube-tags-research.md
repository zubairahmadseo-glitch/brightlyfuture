# Research: YouTube Tags and Keywords: What Still Matters
Cluster 2, sub-topic #7 · Researched 19 October 2026 · Focus keyword: **youtube tags**

## Reader problem (one sentence)
A creator or business uploading videos sees a "Tags" box in YouTube Studio, has read conflicting advice ("tags are a ranking factor" vs "tags are a myth"), and wants to know whether to bother, what to type, how many, and where else their keywords should go instead.

- What tags should I use? Examples?

- How do I add tags (new and existing video)?
- How do I find good tags / see competitors' tags?
- Tags vs hashtags: what's the difference?
- Where do tags appear? Are they public?
- Should I use a tag generator?
- Where should keywords go if not in tags?

## Gaps we can own
1. **YouTube's own words, quoted**, first: tags play a "minimal role"; useful for misspellings. Most competitors still call tags a ranking factor.
2. **The three jobs tags still do**: misspellings, alternative names/abbreviations, and other-language or regional spellings (UK/US). Concrete business examples.
3. **Tags vs hashtags vs keywords**, a clear table, correcting the common mix-up (Shopify's error).
4. **Where your keyword time should go instead**: title, description first lines, spoken words/captions, chapters, thumbnail. Link #6.
5. **Myth check table**: claims from competitors vs what YouTube says (first-tag weighting, 5–8 tags, quotation marks, copying competitor tags, tag generators).
6. **Excessive tags = spam policy**, which nobody explains.
7. **A 2-minute tag routine** (realistic, not a 10-step research process).
