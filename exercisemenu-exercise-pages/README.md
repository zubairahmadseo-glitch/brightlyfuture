- Upload the **_720.gif** version of each GIF to the Media Library, then paste the URL into **GIF CDN URL**.
- Every Meta Title is ≤60 characters, every Meta Description is ≤160, and every Quick Answer is under 60 words and under 320 characters (checked with a script).
- Only verified studies are cited. Each one has a working link in the file.
